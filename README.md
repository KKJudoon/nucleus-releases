# Nucleus Android downloads

Official signed Android APK releases for 星核 Nucleus.

This repository distributes APKs only. Application source is maintained in a separate private repository.

Nucleus can download and install these updates inside the app. Use **Settings → About → Check for updates**. Android will ask you to confirm installation.

The app requires access to your own Nucleus server and your Nucleus account.

Download assets from [Releases](https://github.com/KKJudoon/nucleus-releases/releases). Release notes include the APK SHA-256 checksum.
